# 팻 서바이벌 (Pet Survival)

포켓몬처럼 펫을 모으고 키워서 싸우는 판타지 서바이벌 웹게임.

## 폰에 설치하기
1. GitHub 레포 **Settings → Pages**에서 Source를 **Deploy from a branch**, 브랜치를 게임이 있는 브랜치, 폴더를 `/ (root)`로 저장.
2. 몇 분 뒤 `https://myworld1004.github.io/max/` 주소가 열림.
3. 폰에서 그 주소에 접속한 뒤
   - 안드로이드(Chrome): ⋮ 메뉴 → **앱 설치** 또는 **홈 화면에 추가**
   - 아이폰(Safari): 공유 버튼 → **홈 화면에 추가**

한 번 열고 나면 인터넷 없이도 실행돼요. 게임을 고친 뒤에는 `sw.js`의 `VERSION`을 올리면 설치된 앱도 새 버전으로 바뀌어요.
